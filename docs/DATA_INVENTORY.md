# Data inventory

Populate this file after the source data have been downloaded and inspected.

Minimum inventory:
- site
- modality
- n_participants
- n_rows
- date_min / date_max
- n_participant_days
- actual column names
- missingness
- median epoch
- E∩C sample size
- E∩W sample size
- E∩C∩W sample size
- number of eye-level participants with >=7 valid days
- structural missingness by site and placement
